worktree's agent folders. External plugin caches and arbitrary search URLs are not

excluded explicitly. Discovery is bounded at 25,000 files, 2,000 skill entries per
root and five nested skill levels. Changed-first compares against the current Git
merge base with local main; it is not a persisted per-turn file history.

in an isolated background browser, but those fixtures do not provide desktop IPC,
LAN pairing or real local-host control. No credentials are copied into browser
storage, and width grants no capabilities. On the user's request, foreground

the single auth owner and host reachable. No later wiring, firewall changes,
